Note

This site has no analytics. If you'd like me to know you've read something, the only way is to write to me. That's the entire feedback loop, and it's working as intended.

Heads up

The essays under /writing/notebook are working drafts I publish before they're done. Some are wrong, some are incomplete, some will be deleted. Reading them is reading me think.

Caveat

Opinions on this site are personal, dated, and frequently retired. Quoting them as present-tense positions without checking the publication date is on you.
